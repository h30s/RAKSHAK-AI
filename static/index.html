              Camera Sources

              Connect a webcam or a phone. Every source goes through the same detection and weapon alerts as the CCTV feeds, and appears under Live Sources on the Cameras tab.

              USB webcams show up in this list once plugged in. So does an Android phone (Android 14+) connected by cable with its USB mode set to Webcam.

              1. Connect the phone to the same Wi-Fi as this computer.
              2. Scan the code with the phone's camera.
              3. The page uses a local certificate, so the browser warns once: tap Advanced → Proceed (Safari: Show details → visit this website).
              4. Tap Start camera and allow camera access.

              Connecting an Android phone by cable
              1. On the phone: Settings → About phone, tap Build number (Xiaomi/Redmi: OS version) 7 times to unlock Developer options.
              2. Settings → Developer options (Xiaomi: Additional settings → Developer options): turn on USB debugging.
              3. Connect with a data cable (some cables only charge) and set the USB mode to File transfer.
              4. Tap Allow on the "Allow USB debugging?" prompt, then press Via USB cable again.
              The camera page then opens on the phone: tap Start camera. It works best in Chrome. iPhones can't do this on Windows; use the QR code.
